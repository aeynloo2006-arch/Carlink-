# User Stories - Karbalad
# داستان‌های کاربری - کاربلد

## 1. Customer (مشتری)

- As a customer, I want to search for services so that I can find suitable service providers.
- As a customer, I want to compare providers so that I can choose the best option.
- As a customer, I want to rate providers so that I can share my experience.

## 2. Service Provider (ارائه‌دهنده خدمات)

- As a service provider, I want to create a profile so that customers can find me.
- As a service provider, I want to publish my services so that I can attract customers.
- As a service provider, I want to receive reviews so that I can build my reputation.

## 3. Freelancer (فریلنسر)

- As a freelancer, I want to find projects so that I can earn money.
- As a freelancer, I want to showcase my skills so that employers can evaluate me.

## 4. Employer (کارفرما)

- As an employer, I want to publish job opportunities so that I can find suitable employees.
- As an employer, I want to review candidates so that I can select the right person.

## 5. Job Seeker (جویای کار)

- As a job seeker, I want to search for jobs so that I can find employment.
- As a job seeker, I want to create a professional profile so that employers can learn about me.
