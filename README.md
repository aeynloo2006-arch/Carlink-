CarLink | کارلینک

Your Car, Connected.

پلتفرمی هوشمند برای ارتباط صاحبان خودرو با تعمیرکاران، تعمیرگاه‌ها و خدمات امداد خودرو.

A smart platform connecting car owners with mechanics, repair shops, and roadside assistance services.

درباره پروژه | About

CarLink یک پروژه با هدف ساده‌تر کردن دسترسی به خدمات خودرو است. کاربران می‌توانند تعمیرکاران را جست‌وجو و مقایسه کنند، درخواست تعمیر ثبت کنند و از خدمات امداد خودرو استفاده کنند.

CarLink is a project designed to make automotive services more accessible. Users can search and compare mechanics, submit repair requests, and access roadside assistance services.

امکانات اصلی | Key Features

- جست‌وجو و مقایسه تعمیرکاران | Search and compare mechanics
- مشاهده پروفایل تعمیرگاه‌ها | View repair shop profiles
- ثبت درخواست تعمیر و رزرو نوبت | Submit repair requests and book appointments
- خدمات امداد خودرو و خودروبر | Roadside assistance and towing
- مشاهده امتیازها و نظرات کاربران | View ratings and reviews

وضعیت پروژه | Project Status

در حال تحلیل نیازمندی‌ها، طراحی و مستندسازی اولیه.

Currently in the requirements analysis, design, and initial documentation phase.
